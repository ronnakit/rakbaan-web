## 🤖 ระบบผู้ช่วย AI 2 ระดับ (สัปดาห์ที่ 8)
1. **AI ระดับ 1 — ผู้ช่วยวิเคราะห์หมวดหมู่ช่าง (หน้า `new-job.html`):**
   - ปุ่ม **"🤖 ให้ AI ช่วยวิเคราะห์หมวดหมู่"** 
   - ส่งข้อความหัวข้อและรายละเอียดอาการเสียไปให้ AI (`google/gemini-2.5-flash-lite`) วิเคราะห์
   - ระบบไฮไลต์เลือกการ์ดหมวดหมู่ให้อัตโนมัติ พร้อมแสดงป้าย `💡 ข้อเสนอแนะจาก AI`
   - ผู้ใช้มีอิสระในการคลิกเปลี่ยนหมวดหมู่อื่นได้ตามต้องการ และเป็นผู้กดยืนยันการแจ้งซ่อมด้วยตนเอง
   - มีระบบ Timeout 15 วินาที และ Smart Fallback Engine ป้องกันระบบค้าง
2. **AI ระดับ 2 (Agentic) — ผู้ช่วยประเมินงานช่างและจัดเตรียมเครื่องมือ (หน้า `job-detail.html`):**
   - ปุ่ม **"🤖 ให้ AI ประเมินอาการและจัดเครื่องมือ"**
   - AI รวบรวมข้อมูลงานซ่อมรอบด้าน (หัวข้อ, รายละเอียด, สถานที่, บันทึกการปฏิบัติงานหน้างาน)
   - สรุปผล 4 ด้าน: (1) สาเหตุที่เป็นไปได้ (2) ระดับความเร่งด่วน (3) รายการเครื่องมือและอะไหล่ที่ต้องเตรียมขึ้นรถ (4) ข้อควรระวังความปลอดภัยหน้างาน
   - บันทึกผลลง Cloud Firestore ในฟิลด์ `aiSuggestion`, `aiReason` ของเอกสารงาน และบันทึกประวัติลง subcollection `jobs/{jobId}/aiLog`
   - ⚠️ **AI ไม่ตัดสินใจเปลี่ยนสถานะงานแทนคน** (สิทธิ์การเปลี่ยนสถานะยังคงเป็นของทีมช่าง/แอดมินตาม ACL)

- คีย์ AI ถูกแยกเก็บใน `js/ai-config.js` ซึ่งถูก `.gitignore` คุ้มกันไว้ **ไม่ถูก push ขึ้น GitHub 100%**
- มีไฟล์ `js/ai-config.example.js` เป็นตัวอย่างใน repository
- มีปุ่ม **"🔑 AI Key"** บน Navbar เพื่อให้ผู้ตรวจสามารถป้อน OpenRouter API Key ทดสอบได้โดยตรงผ่าน `localStorage` ของเบราว์เซอร์อย่างปลอดภัย

## 🎯 เกี่ยวกับระบบ
**รักบ้าน@CNX** คือแพลตฟอร์มบริการดูแล ซ่อมแซม และปรับปรุงบ้านครบวงจรสำหรับชาวเชียงใหม่ โดยเว็บพอร์ทัลนี้ (MVP) พัฒนาขึ้นเพื่อให้:
1. **เจ้าของบ้าน (Customer):** แจ้งซ่อมบ้านออนไลน์ ติดตามสถานะงานซ่อม และดูประวัติงานของตนเอง
2. **ทีมช่าง / Staff:** ตรวจสอบงานแจ้งซ่อมทั้งหมดในพื้นที่เชียงใหม่ รับงาน มอบหมายช่าง และอัปเดตสถานะงานตั้งแต่รอรับเรื่องจนซ่อมเสร็จสิ้น

## 📁 โครงสร้างไฟล์
```text
index.html              หน้าหลักและภาพรวมระบบ
jobs.html               รายการงานแจ้งซ่อมทั้งหมด (กรองตามสิทธิ์ผู้ใช้)
new-job.html            ฟอร์มแจ้งซ่อมใหม่ (บันทึกลง Firestore jobs)
job-detail.html         รายละเอียดงาน, เปลี่ยนสถานะ, ลบงาน
login.html              เข้าสู่ระบบ (Firebase Auth)
register.html           สมัครสมาชิกใหม่ (เลือกว่าเป็นเจ้าของบ้าน หรือทีมช่าง)

css/style.css           ชุดรูปแบบธีมรักบ้าน@CNX (ส้ม-ขาว-กรมท่า)
js/firebase-config.js   ตั้งค่าเชื่อมต่อ Firebase (rakbaan-cnx)
js/util.js              ตัวช่วยแปลงข้อความ วันที่ และป้ายสถานะ
js/nav.js               แถบเมนูนำทาง ควบคุมการแสดงผลตามบทบาท (ACL) และตรวจ Auth
js/jobs.js              จัดการหน้ารายการงานซ่อม
js/new-job.js           จัดการการส่งฟอร์มแจ้งซ่อม
js/job-detail.js        จัดการอัปเดตสถานะงานและลบงาน
js/login.js             จัดการการเข้าสู่ระบบ
js/register.js          จัดการการสมัครสมาชิกใหม่

CLAUDE.md               กติกาและข้อกำหนดของระบบ (คอลเลกชัน, สถานะ, ข้อห้าม)
ACL.md                  ตารางสิทธิ์การเข้าถึง 3 บทบาท (ทำได้ / ทำไม่ได้)
firestore.rules         กฎความปลอดภัย Firestore ขั้นต่ำ (บังคับล็อกอิน)
firebase.json           คอนฟิกการ Deploy ขึ้น Firebase Hosting
```

## 🚦 วงจรสถานะงานซ่อม (Job Lifecycle)
`pending_review` (รอรับเรื่อง) ➔ `assigned` (มอบหมายช่างแล้ว) ➔ `in_progress` (กำลังซ่อม) ➔ `completed` (เสร็จสิ้น)
*(หรือ `cancelled` ยกเลิกงาน — ทำได้เฉพาะเจ้าของบ้านในขั้นตอนรอรับเรื่องเท่านั้น)*
